How it works Source

Contribute to the code you already import.

pullkin is a gh extension. It reads your go.mod or package.json, finds each dependency on GitHub, and lists the open issues nobody has picked up yet. You already know these libraries, so you start a step ahead.

gh extension install destinyamba/gh-pullkin

Needs the GitHub CLI, signed in. Works with Go modules and npm.

Four steps, all in the terminal.

Run it in the folder with your manifest. In a monorepo, run it inside each module.

  1. Scan

    Reads go.mod and package.json, then asks deps.dev which GitHub repo each package comes from.

  2. Pick

    Lists issues labeled good first issue, help wanted, and seven similar spellings. Your direct dependencies come before indirect ones, then the most recently active.

  3. Claim

    Press c. pullkin shows the exact comment it will post under your name, and waits for y.

  4. Nudge

    Put gh pullkin nudge in your .zshrc. Each new terminal lists what you claimed and how long ago.

What gets left out, and why.

Every limit is a constant in the source, so you can read the rule instead of guessing at it.

28 days

Recently assigned

Someone was assigned less than four weeks ago. Older assignments stay in the list, since people move on.

Any issue with a linked open pull request is dropped too. Someone is already writing the fix.

3 months

Quiet repos

No push in three months, or archived. A pull request there is unlikely to get a review.

12 months

Forgotten issues

No comments or edits in a year. These are often fixed elsewhere or no longer wanted.

Trade-offs worth knowing.

It relies on labels

Many small libraries never label issues. Run on its own Go dependencies, pullkin finds none. Larger projects label more.

One folder at a time

It reads the manifest in the folder you run it from, not subfolders. That keeps it fast and predictable.

Same claim message everywhere

Some repos ask you to comment /assign. pullkin doesn't read those rules yet, so check CONTRIBUTING.md first.

Go and npm only

Python, Rust, and Java manifests are not read yet.

No AI. Every line comes from your manifest, deps.dev, and the GitHub API. Nothing is posted until you press y.
