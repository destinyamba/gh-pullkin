A gh extension · Go and npm

Fix the code you already use.

pullkin reads your project, finds open issues in your dependencies that you could fix, and helps you claim one. No hunting for a project to care about. You already depend on it.

gh extension install destinyamba/gh-pullkin

How it works

Run it in any folder with a go.mod or package.json.

  1. Scan

    Reads your manifest and finds each dependency's GitHub repo.

  2. Pick

    Lists open issues labeled for newcomers. Direct deps come first.

  3. Claim

    Press c. pullkin shows the comment it will post, and only posts when you say yes.

  4. Nudge

    Add gh pullkin nudge to your shell, and see your open claims every time you start a terminal.

Only issues worth your time

pullkin drops anything you can't finish or won't get reviewed.

Taken

  • Has a linked open pull request
  • Assigned in the last 28 days

Stale

  • No activity in 12 months

Dead repo

  • Archived
  • No push in 3 months

No AI

Every answer comes from your files and real GitHub data. Nothing is guessed, and nothing is posted without your yes.
